# Simple Schedule Card (Home Assistant)

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/hacs/default)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![Version](https://img.shields.io/badge/Version-1.0.0-green.svg)](https://github.com/)

Легка, зручна та сучасна кастомна картка Lovelace для керування вбудованими планувальниками розкладів (`schedule`) та автоматизаціями в **Home Assistant**.

---

## ✨ Основні можливості

- **📅 Тиждень з Понеділка**: Європейський стандарт (Понеділок – Неділя).
- **🇺🇦 Повна українська локалізація**: Усі назви днів, категорій приладів, статусів та помилок перекладені українською мовою (з автоматичною англійською за замовчуванням).
- **⏱️ Числове відображення інтервалів**: Опціональний перемикач «Показувати час», який відображає точні години роботи (`06:30–08:30, 17:30–22:30`) поруч із кожним днем.
- **⚡ 100% нативні об'єкти Home Assistant**: Створює стандартні хелпери `schedule.*` та автоматизації `Schedule · [Назва]`. Жодних важких сторонніх демонів чи непідтримуваних залежностей.
- **🎛️ Підтримка багатьох типів пристроїв**:
  - Термостати та кондиціонери (`climate`) — з налаштуванням температури та режимів (обігрів, охолодження, авто)
  - Бойлери та водонагрівачі (`water_heater`)
  - Освітлення (`light`) — з регулюванням яскравості
  - Реле та розетки (`switch`)
  - Штори та жалюзі (`cover`)
  - Крани та клапани (`valve`)

## 🚀 Встановлення

### Спосіб 1: Через HACS (Рекомендовано)

1. Відкрийте **HACS** → **Інтерфейс** (Frontend).
2. Натисніть **три крапки ⋮** у правому верхньому кутку → **Користувацькі репозиторії** (Custom repositories).
3. Додайте посилання на цей репозиторій:
   - Категорія: **Lovelace**
4. Натисніть **Завантажити**.
5. Оновіть сторінку браузера.

---

### Спосіб 2: Вручну

1. Завантажте файл `simple-schedule-card.js` з останнього релізу.
2. Скопіюйте його на ваш сервер Home Assistant у папку:
   ```text
   /config/www/simple-schedule-card.js
   ```
3. У Home Assistant відкрийте:
   **Налаштування → Панелі керування → Ресурси** (три крапки вгорі праворуч).
4. Додайте ресурс:
   - **URL:** `/local/simple-schedule-card.js?v=1.0.0`
   - **Тип ресурсу:** `JavaScript Module`
5. Очистіть кеш браузера (`Ctrl+F5`).

## 📋 Приклад використання в Lovelace

Додайте картку на будь-яку панель керування:

```yaml
type: custom:simple-schedule-card
title: Розклади розумного дому
show_add: true
show_time: true # опціонально: показувати інтервали цифрами
show_time_toggle: true # опціонально: чекбокс перемикання часу в шапці (true/false)
```

### Додаткові параметри:

| Параметр | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `title` | `string` | `Розклади` | Заголовок картки |
| `show_add` | `boolean` | `true` | Відображати кнопку «+ Новий розклад» |
| `show_time` | `boolean` | `false` | Відображати години інтервалів цифрами поруч із графіком |
| `show_time_toggle` | `boolean` | `true` | Відображати інтерактивний чекбокс перемикання часу в шапці картки |
| `height` | `string` | `auto` | Фіксована висота (наприклад, `450px` або `50vh`) |
| `device_domains` | `list` | `all` | Фільтр категорій пристроїв для вибору |

## 💻 Локальна розробка та запуск

Для розробників (зокрема якщо ви звикли до Java/Python стеків):
- `package.json` — аналог `pom.xml` / `build.gradle` або `pyproject.toml`.
- `node_modules/` — локальні бібліотеки (аналог `.venv` або `.m2`).

### 1. Встановлення залежностей:
```bash
npm install
```

### 2. Запуск інтерактивного тестового стенду в браузері:
```bash
npm run dev
```
Відкрийте `http://localhost:3000` у браузері. Тут працює інтерактивний симулятор Home Assistant з підтримкою гарячого перезавантаження (HMR).

### 3. Збірка релізного бандла для Home Assistant:
```bash
npm run build:card
```
Створює готовий файл `simple-schedule-card.js` для папки `/config/www/`.

### 4. Запуск юніт-тестів:
```bash
npm test
```
